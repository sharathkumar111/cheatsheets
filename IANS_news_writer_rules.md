# IANS International Desk — Copy Filing Rules (ksk/)

Handed over from the cloud writing session. Follow every rule below for every copy.

## 1. Format
- Headline, then a blank line, then: `City, Mon D (IANS)` lead paragraph.
- End with `--IANS` and, on the next line, `ksk/`.
- Always give the EXACT word count (headline + body, excluding `--IANS` and `ksk/`). Count with a script, never estimate.
- Length: 300 words minimum (mandatory). About 400 preferred. Do not go far over (600+ is too long). If asked for "longer", go above 300.
- No bullet points in copy. No semicolons in headlines. Simple headlines when asked.
- Numbers one to nine as words in our own text (e.g. "ninth", "two"), not in quotes.
- After the copy, always list background links (IANS links in a plain code block so they copy cleanly), most recent first.

## 2. Leads and headlines
- Lead with the LATEST / NEW point. Never lead or headline with old news already filed or already reported in a previous IANS story. Check ianslive.in first for what was already filed and say what is new.
- Never start a story with "Asked about...".
- MEA briefing copies: lead says "...the Ministry of External Affairs (MEA) said on <day>".
- Media/agency-based copies (reports, TASS, IRNA, Gulf News, OpIndia, etc.): first paragraph ends with "a report said" or "local media reported" — do NOT name the outlet in the first paragraph. Name the outlet lower down (once or twice), and use "the report said / stated / noted" elsewhere. If you remove the outlet name from the lead, you MUST add it somewhere lower.
- Pro-India angle preferred, but stay truthful. For Pakistani officials, be neutral and truthful — not supportive. Don't frame Pakistan as the one offering solutions.
- Don't put business/trade items in the lead when there is a bigger point (e.g. Quad: terrorism first; business forum at the end).
- Make headline attribution unambiguous (don't make it look like a person said something they didn't).
- Use "EAM Jaishankar" / "External Affairs Minister (EAM) S. Jaishankar" — never just "Jaishankar".
- Expand titles/acronyms at first mention (e.g. "Rear Admiral" not "RAdm" in our own text; MEA, MoD, etc.).

## 3. Sources and background
- Background ONLY from IANS stories on ianslive.in. Max two background stories, most recent first.
- Copy background lines as written; change only tense, days and grammar. Don't rewrite unnecessarily. Keep the original attributions (e.g. "Nepali officials said").
- Give each background paragraph a clear date ("On November 14", "In August") so "earlier that month" doesn't mislead.
- Background must be RELEVANT (no Diwali in a defence copy, no cricket match in an exercise copy, etc.).
- When IANS has no story, ANI or other outlets may be used for general info only, paraphrased.
- Only official government sources may be added beyond what the user pasted (no random media houses).
- If the user says "don't add background", add none.
- When the user says "take only from X", take ONLY from X.

## 4. Banned / restricted sources
- NO Reuters. If a report is Reuters-based (e.g. "spoke to Reuters", "no immediate comment"), drop the report entirely and say so. AFP-derived facts are questionable.
- Don't cite the Kathmandu Post.
- Don't use a writer's own personal case/anecdote.
- Never get past paywalls or bot checks.

## 5. No invention — accuracy rules
- No assumptions, no invented framing lines ("The visit is aimed at..." etc.). Write only what is given or in IANS background.
- Don't assume days. Use a day only if the post says "today" with a known posting date, or the source states it. If unknown, leave the day out.
- Media advisories: do NOT write times, venues, arrival points (e.g. "AFS Palam", "Hotel Taj Mahal", "Rail Bhawan"). Only who meets whom and which day.
- If a scheduled event (from an advisory/schedule) is now in the past and not confirmed, remove it or flag it to the user — never present it as "scheduled" after the day has passed.
- Don't quote search-result snippets as if they were the article. If a page can't be read, ask the user to paste it.
- Check names and handles online; replace @handles with real names, remove # and emojis, replace flags with country names, fix obvious typos in quotes (and say so).

## 6. Quoting
- Quote the ENTIRE post/tweet (can be split into multiple quotes).
- Big quote chunks with 1–3 line paraphrase bridges between them. No two consecutive quote paragraphs without a bridge clause.
- If quotes are too long, break them and paraphrase.
- Mark cut text inside a quote with "...".
- Don't put reported speech inside quote marks.

## 7. Recurring formats (follow previous IANS stories)
- Gift stories (PM gifts): one-line lead naming the gifts and recipient, then each gift's description paragraph by paragraph, no background.
- Bangladesh dengue updates: "<N> more people died due to dengue in Bangladesh in the 24 hours till 8 am (local time) on <day>, taking the country's death toll from the mosquito-borne disease in 2026 to <X>, local media reported..." then DGHS / UNB figures, then the standard background (Tuku warning, Daily Star experts).
- Paank / Baloch disappearances: Quetta dateline; "a leading human rights organisation said"; "The latest incident comes against the backdrop of a growing wave of extrajudicial killings and enforced disappearances across the province"; Paank = "the Human Rights Department of Baloch National Movement (BNM)".
- Diaspora reactions: quote each speaker by name; unnamed speaker = "an Indian diaspora member".

## 8. Practical
- IANS search: https://ianslive.in/search/<term+term>; story pages read with curl.
- MEA documents: https://www.mea.gov.in/FrontEnd/FetchPublicationDetailData?pkid=<id>&languageId=1
- PIB: https://www.pib.gov.in/PressReleaseIframePage.aspx?PRID=<id>&reg=3&lang=2
- When the user wants a list of links (e.g. "live links of international stories"), put it in a plain code block so numbers copy.
